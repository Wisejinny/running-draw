# 달리기 뽑기 (Run Draw)

학생 명단을 넣으면 도시 속 경기장에서 달리기 경주를 해서 당첨자를 뽑는 웹앱이에요.

- 거리: 곧게 뻗은 길 100m / 200m / 300m (모두 같은 출발선)
- 당첨 기준: 먼저 도착 / 꼴찌 도착 / 순위 지정
- 배경: 경기장 / 강변 도시 / 밤 불꽃 / 푸른 언덕 / 아침 안개 / 파란 하늘 (AI로 만든 사진)
- 코스 종류: 달리기 / 허들 넘기 (허들 10개, 가끔 걸려 넘어뜨려요)
- 배경 음악: 비트 / 응원가 / 댄스 / 잔잔한 (Web Audio로 직접 연주, 결승이 가까워지면 템포가 빨라져요)
- `이름*3` 처럼 쓰면 같은 이름의 주자가 3명 나가요.
- 즐겨찾기 명단 저장, 당첨자 빼고 다시 뽑기, 음악·효과음

빌드 과정 없이 `index.html`을 열면 바로 실행돼요.
