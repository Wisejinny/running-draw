# 경주 뽑기 (Race Draw)

학생 명단을 넣으면 육상·경주마·사이클·조정·스키·수영 경기장에서 경주를 해서 당첨자를 뽑는 웹앱이에요.

- 종목: 육상(100·200·300m, 허들) / 경주마(타원 경마장) / 사이클(벨로드롬) / 조정(레가타 코스) / 스키(활강 사면) / 수영(50m 풀, 왕복)
- 참가자: 이름마다 성별·피부·머리·옷·장비가 달라요 (말 털색과 기수복, 자전거 프레임, 보트 색, 스키복, 수영모 등)
- 관중: 스탠드의 관중이 결승이 가까워질수록 환호하고, 박수·함성·심장박동·스네어 롤·에어혼 효과음이 나와요
- 당첨 기준: 먼저 도착 / 꼴찌 도착 / 순위 지정
- 배경: 경기장마다 AI로 만든 사진 배경 (육상은 6가지 사진 중 선택)
- 배경 음악: 비트 / 응원가 / 댄스 / 잔잔한 (Web Audio로 직접 연주, 결승이 가까워지면 템포가 빨라져요)
- `이름*3` 처럼 쓰면 같은 이름의 주자가 3명 나가요.
- 즐겨찾기 명단 저장, 당첨자 빼고 다시 뽑기, 음악·효과음

빌드 과정 없이 `index.html`을 열면 바로 실행돼요.
